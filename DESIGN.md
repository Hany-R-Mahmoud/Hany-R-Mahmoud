# Design Contract

## Direction

Hybrid: cinematic hero, editorial portfolio body. The profile should feel like a builder's product reel, not a generic developer badge board.

## Palette

- Ink: `#08111f`
- Night: `#0f172a`
- Cloud: `#e6f4ff`
- Muted: `#9fb4c9`
- Cyan: `#22d3ee`
- Green: `#34d399`
- Amber: `#f59e0b`
- Rose: `#fb7185`
- Violet: `#8b5cf6`

## Motion

Use linked SVG with SMIL animation:

- slow grid drift
- scanning beams
- orbiting nodes
- staggered text and project markers
- reduced visual noise through low opacity backgrounds

## Typography

GitHub SVG assets can use system stacks for reliability. README body relies on GitHub rendering, so hierarchy comes from short headings, tables, badges, and asset rhythm.

## Components

- animated hero SVG
- production website preview PNG per selected project
- alternating project tables
- clear badge actions: Live Site, Public Repo, Contact

## Anti-References

- generic purple-only AI gradient
- wall of badges before the story
- many identical card sections
- fake stats, invented project framing, or invented repository links
- long paragraphs that bury the product list
